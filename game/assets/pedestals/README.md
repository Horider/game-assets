# Постаменты под персонажей — по одному на локацию

Пиксель-арт постаменты для четырёх локаций игры. В игру пока не подключены.

| Папка | Локация | Что шевелится |
|---|---|---|
| `forest-outpost` | Лес: срез пня с кольцами, мох, мухомор | травинки у основания, падающий листик |
| `marsh-crossing` | Болото: каменная плита во мху, лужа | камыши, свисающий мох, рябь, пузырёк |
| `ruined-cemetery` | Кладбище: старая плита с трещинами, плющ, черепок | пламя свечи и отблеск, сухая трава |
| `frost-pass` | Ледяной перевал: камень под снежной шапкой, сосульки | искры на льду, капля с сосульки, снежинка |

В каждой папке:

- `frame-01.png` … `frame-05.png` — прозрачные PNG 128 × 96, размер и положение постамента одинаковые во всех кадрах;
- `spritesheet.png` — прозрачная строка 640 × 96, пять кадров слева направо;
- `preview.gif` — зацикленное превью (180 мс на кадр) на тёмном фоне.

`overview.png` показывает все четыре анимации. Верх постамента — эллипс с центром в точке (64, 54) в координатах кадра, ширина ≈ 100 px: туда ставятся ноги персонажа.

`build_pedestals.py` рисует всё заново (нужен Pillow): `python build_pedestals.py`.
