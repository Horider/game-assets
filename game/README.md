# Последний форпост

Первая играбельная версия обороны пяти дорог. Откройте `index.html` в браузере.

1. Выберите одну из четырёх локаций в меню.
2. Выберите уровень лучника внизу экрана (или нажмите клавиши 1–4).
3. Нажмите на свободную нарисованную плиту дорожки. Лучник встанет в её центр и автоматически начнёт стрелять по оркам на этой дорожке.
4. Нажмите на уже стоящего лучника, чтобы улучшить его на один уровень за половину цены следующего уровня. Перепрыгнуть через уровень нельзя.
5. Продержитесь четыре волны. Прорыв пяти орков означает поражение.

Монеты поступают со временем, за убийства и между волнами. Пробел ставит игру на паузу, кнопки 1x / 2x / 3x в шапке меняют скорость.

Все игровые числа находятся в `balance.js`: стоимость и характеристики лучников, здоровье и поведение орков, доход, волны и сложность локаций. Проверка логики: `node game/smoke-test.cjs` из корня репозитория.
