# Анимированные эффекты локаций

Для каждой из четырёх локаций создан отдельный прозрачный слой размером **1672 × 941**. Исходные фоны в `locations/` не изменены. Наложите соответствующий `frame-NNN.png` поверх фона с тем же именем.

| Папка | Эффект |
| --- | --- |
| `frost-pass` | снегопад по всей локации |
| `marsh-crossing` | движущиеся и мерцающие светлячки над водой и у мостков |
| `ruined-cemetery` | медленно плывущий туман; окно дальнего замка вспыхивает раз в 5 секунд |
| `forest-outpost` | тёплое пульсирующее свечение вокруг существующих фонарей и огней |

В каждой папке есть `frame-000.png` … `frame-049.png`, а также `preview.gif` с эффектом поверх фона и полноразмерный `sample.png`. Все PNG-кадры сохраняют прозрачность. Обзор четырёх примеров находится в `overview.png`.

**Воспроизведение:** 10 кадров в секунду, зацикленный набор из 50 кадров длится 5 секунд. Для кладбища короткая вспышка замка находится в кадрах 46–48 и повторяется один раз за цикл. Порядок отрисовки: фон → объекты игрового поля → атмосферный слой; для тумана при необходимости можно поместить персонажей поверх атмосферного слоя, если они должны оставаться контрастными. Подробности машинного чтения — в `manifest.json`.

Скрипт `build_effects.py` пересоздаёт последовательности из исходных фонов. Требуется Pillow. `preview.gif` уменьшен вдвое для просмотра; в игре используйте полноразмерные PNG.
