# Анимированные объекты для локаций — версия 3

Девять отдельных анимаций, каждая состоит из пяти кадров. В каждой папке:

- `frame-01.png` … `frame-05.png` — отдельные прозрачные PNG 128 × 128;
- `spritesheet.png` — прозрачная полоса 640 × 128, пять кадров слева направо;
- `preview.gif` — зацикленное превью;
- `source.png` или `transition-source.png` — исходник для пересборки.

`frog-croak`: спокойная поза → горло начинает надуваться → полунадутое горло → полное кваканье → горло сдувается. Лягушка сидит на месте во всех пяти кадрах.

`frog-jump`: приседание → отталкивание → полёт → спуск → приземление. Кваканья в этом цикле нет.

`flag`: белая ткань без рисунка, пять фаз колыхания на неподвижном древке.

Остальные объекты: `water-bubbles`, `torch`, `skeleton-hand`, `zombie-hand`, `snowball`, `crow`. `overview.png` показывает все анимации. Скрипт `build_props.py` пересобирает кадры, спрайт-листы, GIF и обзор из включённых исходников; требуется Pillow.

Текст запросов для генерации обновлённых исходников находится в `PROMPTS.md`. Для переноса в игровой движок используйте прозрачные PNG, а GIF оставьте для просмотра.
