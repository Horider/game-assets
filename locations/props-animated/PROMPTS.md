# Prompts for the revised artwork

The following images were made with the built-in ImageGen tool using transparent backgrounds and local visual references. The source PNGs are included in the relevant asset folders.

## Frog croak

> Using the supplied existing frog strip as the character reference, make a new horizontal strip with exactly five separate equal-width frames of the same small olive-brown frog croaking while seated on the ground. Frame 1: calm seated frog, flat throat. Frame 2: throat just beginning to inflate, mouth barely open. Frame 3: throat visibly half inflated. Frame 4: full pale cream balloon-shaped vocal sac, open croaking mouth, most expressive peak. Frame 5: sac deflates and mouth closes while frog remains seated. Show five genuinely distinct stages, in left-to-right order. Same three-quarter side view facing right, same body and hind-leg position, size, scale, baseline, pixel palette, dark crisp outlines and chunky hand-placed pixels as the reference. The frog must not jump or move across cells. One frog per cell, no overlaps, words, grid, scenery, or background; genuinely transparent PNG.

## Frog jump

> Using the supplied existing frog strip and the airborne reference pose, make a new horizontal strip with exactly five separate equal-width frames of the same small olive-brown frog performing one complete jump and landing. Frame 1: low crouch on ground. Frame 2: hind legs push off, body rises. Frame 3: clearly airborne and horizontal with both hind legs extended behind. Frame 4: descending, front feet reach toward ground and hind legs fold. Frame 5: fully landed in a low compact crouch, matching the initial ground level. Show five distinct sequential stages in left-to-right order. Same three-quarter side view facing right, olive-brown skin, pale cream throat, dark outlines, chunky hand-placed pixel art as reference. No croaking or inflated throat. One frog per cell, no overlaps, words, grid, scenery, or background; genuinely transparent PNG.
