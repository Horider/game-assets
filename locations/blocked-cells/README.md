# Закрытые клетки

Восемь анимированных препятствий: по два для каждой локации. Каждый цикл состоит из пяти кадров с плавным движением на месте.

| Локация | Варианты |
| --- | --- |
| Лесной аванпост | тюк сена, замшелый пень |
| Морозный перевал | снежный завал, обледенелые валуны |
| Болотная переправа | ком грязи, сплетение корней |
| Разрушенное кладбище | надгробие, груда костей |

В каждой папке: `frame-01.png` … `frame-05.png` — прозрачные PNG 128 × 128; `spritesheet.png` — прозрачная полоса 640 × 128; `preview.gif` — зацикленное превью; `source.png` — исходная полоса для пересборки. `overview.png` показывает все циклы.

Для игрового движка используйте PNG. Рекомендуемая скорость — около 180 мс на кадр. Кадры остаются центрированными на одной базовой линии. Пересборка: `python build_blocked.py` при наличии Pillow.
