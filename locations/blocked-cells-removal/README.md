# Удаление закрытых клеток

Отдельные одноразовые анимации растворения для всех восьми препятствий из `../blocked-cells/`. Каждая папка содержит пять прозрачных PNG 128 × 128, спрайт-лист 640 × 128, GIF-превью и исходную полосу `source.png`.

Фазы: 1 — исходный целый блок; 2 — распад краёв; 3 — примерно половина блока; 4 — последние фрагменты; 5 — полностью прозрачная клетка. Анимация не зацикливается в игре. При попытке удаления замените обычный спрайт этой анимацией, проиграйте её один раз, затем уберите блок и разблокируйте клетку.

Первый кадр совпадает с исходным статическим спрайтом. Положение и размер кадра сохраняются на всём переходе. Для пересборки нужен Pillow: `python build_removal.py`.
