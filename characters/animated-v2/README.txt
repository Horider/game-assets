Animated pixel-art sprite sheets for four hero classes.
Archer and shieldbearer levels 1-3: 1448 x 1086 px; 4 columns x 3 rows; nominal cell size 362 x 362 px.
Warrior levels 1-4: 1619 x 971 px; 5 columns x 3 rows; nominal cell size about 324 x 324 px.
Healer level 1: 1620 x 971 px; levels 2-4: 1619 x 971 px. All use 5 columns x 3 rows; nominal cell size about 324 x 324 px.
Row 1: idle, frames left to right.
Row 2: run, frames left to right.
Row 3: class action, frames left to right.
Archer action: shoot. Warrior action: sword-attack arm motion (the sword is a separate asset). Shieldbearer action: defend. Healer action: heal.
Levels 1, 2 and 3 upgrade equipment while retaining each character identity; the healer and warrior also have level 4.
The warrior has five frames in every row at every level. All warrior hands are empty so the sword can be layered separately.
The healer holds the staff in the right hand in every frame of all four levels, including the full run cycle, and keeps both arms visible during healing.
Transparent background. These are concept animation sheets; review cell boundaries and frame alignment before using them as final engine sprites.

Shieldbearer extended sheets (shieldbearer-level-1-5frames.png through shieldbearer-level-3-5frames.png):
1810 x 1086 px, 5 columns x 3 rows, 362 x 362 px cells. Rows: idle, run, defend.
The first four frames of each row are pixel-identical to the corresponding original sheet.

Shieldbearer level 4 (shieldbearer-level-4.png):
1448 x 1448 px, 4 columns x 4 rows, 362 x 362 px cells.
Rows: idle, run, defend, shield bash. Each row contains four sequential frames.

Shieldless shieldbearer variants (shieldbearer-level-1-no-shield.png through
shieldbearer-level-4-no-shield.png) keep the same grid and 362 x 362 px cell
size as their corresponding extended sheets. The shield-side hand is empty for
adding a separate shield overlay. The other hand holds a mace in every frame,
including raised-arm defense and shield-bash poses.
